# Menús internos: organización por tarea

Base: `f86ddc0`. El usuario indica expresamente que hay demasiadas opciones dentro de los apartados. Esta entrega reorganiza los controles internos; conserva las seis secciones, las rutas, los permisos y las operaciones existentes.

## Componentes y accesibilidad

- `TaskNavigation` separa las vistas de tareas de la configuración y valida la vista de retorno (`mine`, `all`, `cancelled`). La fecha se conserva.
- `ExpensesNav` diferencia destinos de uso habitual del historial de cambios. Todas las URLs anteriores siguen funcionando; el historial mantiene su estado activo aunque esté fuera de las pestañas.
- `SectionDisclosure` utiliza `details` y `summary` nativos. No usa un rol ARIA de menú para contener formularios. Se activa con teclado, conserva los campos montados al plegarse y respeta los tokens y la reducción de movimiento existentes.
- `MessageActions` conserva exactamente los callbacks de respuesta, edición, confirmación de eliminación y reacción. Editar solo se ofrece para mensajes propios; todos sus botones se deshabilitan durante una operación pendiente.
- Los controles mantienen áreas táctiles de al menos 44 px. Se corrigió el ancho del selector de tareas para evitar texto cortado. En pantallas de hasta 360 px se reduce el espaciado de las pestañas, conservando el tamaño de letra y el desplazamiento horizontal para etiquetas más largas.

No se añaden dependencias, pantallas, tablas, almacenamiento de navegación, portales ni modales. Los formularios financieros, las acciones servidor, la generación y reconciliación, SQL y RLS no se modifican.
